# Task Manager API

FastAPI приложение для управления задачами.

## Возможности

- Создание задач с названием (3-100 символов), описанием и приоритетом (1-5)
- Получение задачи по идентификатору
- Валидация входных данных
- Автоматическая генерация ID для новых задач

## Запуск

1. Установите зависимости:
```bash
pip install fastapi uvicorn
```

2. Запустите сервер:
```bash
uvicorn тест1:app --host 0.0.0.0 --port 8000
```

3. Откройте документацию API:
- Swagger UI: http://127.0.0.1:8000/docs
- ReDoc: http://127.0.0.1:8000/redoc

## Эндпоинты

### POST /tasks

Создает новую задачу.

**Тело запроса:**
```json
{
  "title": "Название задачи",
  "description": "Описание задачи (опционально)",
  "priority": 3
}
```

**Ответ:** HTTP 201 Created с данными созданной задачи.

### GET /tasks/{task_id}

Получает задачу по ID.

**Ответы:**
- HTTP 200 OK — задача найдена
- HTTP 404 Not Found — задача не найдена
